# DinDin

Despesas e receitas da casa, com login Google e acesso liberado pelo administrador.

## Protótipo clicável

Abra `prototipo/index.html` no navegador (duplo clique). Não precisa instalar nada.

Telas: Entrar, Acesso não liberado, Início do mês, Novo lançamento, Foto da nota, Pessoas e acessos, Orçamento, Fixos e parcelas.

Os nomes e valores são de exemplo e voltam ao início ao recarregar a página. A leitura da foto é simulada.

Para publicar no GitHub Pages: Settings > Pages > Deploy from a branch > `main` / root. O endereço fica `https://acanteiro-digital.github.io/din-din/prototipo/`.
